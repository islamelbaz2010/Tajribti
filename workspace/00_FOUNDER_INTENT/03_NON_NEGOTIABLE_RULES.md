# NON-NEGOTIABLE RULES
## These Rules Cannot Be Unlocked by Any AI Session

**If any recommendation violates a rule on this page, reject the recommendation immediately.**

---

## RULE 1 — COMMERCIAL VALIDATION FIRST

Engineering begins ONLY after the Founder issues a written Track 0 GO decision.

Until that decision:
- Zero production code
- Zero API design
- Zero database migrations
- Zero infrastructure provisioning
- Zero Flutter implementation
- Zero React implementation
- Zero backend services

Current authorization: **COMMERCIAL ACTIVITIES ONLY.**

*Source: `15_Decisions/FOUNDER_DECISIONS.md` BD-13 LOCKED; `13_Audits/REMEDIATION_REAUDIT.md` REM-04 LOCKED; `AI_BOOTSTRAP/11_AI_RULES.md` RULE-AI-03*

---

## RULE 2 — THE KILL CRITERION IS ABSOLUTE

> *"If you don't get 5 interested companies in the discovery phase, don't start coding."*

3 signed LOIs = Track 0 GO → engineering begins.  
Fewer than 3 signed LOIs in 60 days = NO-GO → no engineering. Period.

**This criterion cannot be waived. It cannot be extended. It is the commercial thesis test.**

*Source: `07_Product/GO_TO_MARKET.md` — Kill Criterion; `12_Reviews/PEER_REVIEW_MASTER_REPORT.md`; `15_Decisions/FOUNDER_DECISIONS.md` BD-14 LOCKED*

---

## RULE 3 — MOBILE FIRST. ALWAYS.

The consumer experience belongs to the Flutter mobile application. No exception.

Never:
- Recommend a website MVP instead of the mobile app
- Move QR scanning to a browser
- Move surveys to a browser
- Move consumer identity to a website
- Move rewards to a website
- Move push notifications to a website

The Corporate Website is marketing infrastructure only. It acquires leads. It does not host the product.

*Source: `15_Decisions/FOUNDER_DECISIONS.md` TD-01 LOCKED; `docs/governance/PROJECT_ARCHITECTURE_CONSTITUTION.md` CAD-06*

---

## RULE 4 — NEVER CALL IT A SAMPLING COMPANY

**The only acceptable description: Consumer Intelligence Platform (B2B2C).**

Using "sampling company," "activation agency," "field marketing company," "promotional operator," or "logistics operation" as the category description is a strategic error. The sampling is the acquisition mechanic. The data is the product.

*Source: `AI_BOOTSTRAP/11_AI_RULES.md` RULE-AI-01; `AI_BOOTSTRAP/01_PROJECT_CONSTITUTION.md`*

## RULE 5 — ALL FINANCIAL FIGURES ARE ILLUSTRATIVE

Campaign price range ($4K–$20K), MVP cost ($90K–$120K), break-even (18–24 months), gross margin (~60%) — all of these are unvalidated estimates.

**Always qualify:** "ILLUSTRATIVE — not validated. Track 0 pricing discovery will produce real data."

*Source: `AI_BOOTSTRAP/11_AI_RULES.md` RULE-AI-02; `15_Decisions/FOUNDER_DECISIONS.md` FIN-01 LOCKED*

## RULE 8 — NO SCOPE EXPANSION WITHOUT FOUNDER INSTRUCTION

If a recommendation introduces any concept, feature, revenue stream, market, or approach that does NOT already exist in the repository:

```
STOP.
Report the drift to the Founder.
State: "This concept is not in the repository. Proceeding would expand scope."
Do not continue until the Founder confirms.
```

## RULE 10 — NEVER OVERRIDE LOCKED DECISIONS

If a decision is marked LOCKED in `03_FOUNDER_DECISIONS.md`, an AI may:
- Explain the rationale
- Surface risks or trade-offs
- Present new evidence that bears on it

An AI may NOT:
- Suggest reversing it without explicit Founder instruction
- Treat it as "up for discussion"
- Propose alternatives as if the decision hasn't been made

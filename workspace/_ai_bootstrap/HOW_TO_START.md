# How To Start — Workspace Guide

---

## If you are a new team member

1. Read `AI_CONTEXT.md` first — 2 minutes. Gives you the complete picture.
2. Read `01_Project_Overview/PROJECT_OVERVIEW.md` — understand the business
3. Read `15_Decisions/FOUNDER_DECISIONS.md` — understand every locked decision
4. Read `13_Audits/REMEDIATION_REAUDIT.md` — understand current authorization status and what's blocking

---

## If you are a developer

1. `AI_CONTEXT.md` (2 min)
2. `09_Technical/TECHNICAL_ARCHITECTURE.md` — full stack and architectural decisions
3. `08_PRD/MASTER_PRD_v1.0.md` — feature requirements and data model
4. `02_Project_Management/MASTER_DELIVERY_PLAN.md` — sprint schedule and your upcoming work
5. `DECISION_INDEX.md` — specifically the ADR section for architecture decisions

---

## If you are an investor or reviewer

1. `04_Investment/INVESTMENT_DUE_DILIGENCE_REPORT_v2.md` — canonical investment report (19K words)
2. `12_Reviews/PEER_REVIEW_MASTER_REPORT.md` — independent peer review with corrections
3. `16_Reports/QUALITY_REPORT.md` — known gaps and quality assessment
4. `13_Audits/REMEDIATION_REAUDIT.md` — current readiness status

---

## If you are an AI assistant working on this project

1. Load `AI_CONTEXT.md` into your context
2. Load `LOADING_ORDER.md` for optimal context loading sequence
3. Load `PROJECT_GLOSSARY.md` for terminology
4. Load the specific document relevant to your task
5. Never treat financial figures as validated — all illustrative
6. Development is NOT authorized — do not generate code until Track 0 GO is confirmed

# Project Constitution — Tajribti

**This file defines what this project fundamentally IS and IS NOT. These definitions govern all reasoning.**

---

## What This Project IS

### Category Definition

A **Consumer Intelligence Platform** — a technology-enabled platform that collects structured, permission-based consumer behavioral data at the moment of first product trial and monetizes that data as brand intelligence.

*Source: `04_Investment/INVESTMENT_DUE_DILIGENCE_REPORT_v2.md` — Executive Conclusion; `01_Project_Overview/PROJECT_OVERVIEW.md`*

### The Mechanic

Physical product sampling is the **consumer acquisition mechanic only**. It lowers the barrier to participate and earns the right to collect first-party data. The sample is not the product.

*Source: `04_Investment/INVESTMENT_DUE_DILIGENCE_REPORT_v2.md` — Core Investment Thesis*

### The Business Model (B2B2C)

| Party | Gives | Receives |
|---|---|---|
| Brand (paying customer) | Campaign fee ($4K–$20K/campaign — ILLUSTRATIVE) | Structured consumer data, demographics, purchase intent, survey responses |
| Consumer (data source) | Demographic profile + post-trial survey (3–5 questions, <3 min) | Free product sample + rewards |
| Tajribti (intermediary) | Platform, logistics coordination, data layer | Revenue: campaign fees + per-sample fees + AI dashboard subscription + panel access + Enterprise API |

*Source: `_ai_bootstrap/AI_CONTEXT.md` Section 3; `15_Decisions/FOUNDER_DECISIONS.md` Business Decisions*

### Revenue Model (Locked)

1. Campaign fees (brand pays per campaign)
2. Per-sample fees (brand pays per verified trial)
3. AI dashboard subscription (recurring access to insights)
4. Panel access (access to defined demographic segments)
5. Enterprise API (data integration for large accounts)

*Source: `15_Decisions/FOUNDER_DECISIONS.md` BD-09*

### The Moat (Long-term Defensibility)

The proprietary first-party consumer dataset + brand relationships. Every campaign makes the dataset more valuable. The data accumulation flywheel is the actual competitive moat — not the technology.

*Source: `04_Investment/INVESTMENT_DUE_DILIGENCE_REPORT_v2.md` — Core Investment Thesis; `10_AI/AI_STRATEGY.md`*

## Non-Goals (Explicit Exclusions)

### Sector non-goals (Years 1–3)

Healthcare (clinical), insurance, banking, telecom, government, education.

*Source: `15_Decisions/FOUNDER_DECISIONS.md` BD-07*

### Product non-goals (MVP)

- Permanent kiosk installations
- Owned product logistics
- E-commerce layer
- Paid consumer subscriptions
- Non-FMCG verticals
- GCC features
- HubSpot/Salesforce CRM integration
- Enterprise API
- LLM insight generation (AI narratives deferred to V2)

*Source: `15_Decisions/FOUNDER_DECISIONS.md` PD-03, PD-07; `08_PRD/MASTER_PRD_v1.0.md`*

### Geographic non-goals (Year 1)

Anywhere outside Cairo. Alexandria, Giza, New Cairo, 6th October are Year 2.

*Source: `15_Decisions/FOUNDER_DECISIONS.md` BD-04, BD-05*

### Strategic non-goals

- Venture-style forced exit timeline (explicitly rejected)
- Open-sourcing Tajribti's code or models
- Single-LLM-vendor commitment
- Multi-cloud in Years 1–2
- RAG / vector database for V2 (deferred to validated need only)

*Source: `15_Decisions/FOUNDER_DECISIONS.md` TD-17, TD-18; `10_AI/AI_STRATEGY.md`*

## Core Values (From Master Execution Blueprint)

1. Evidence over opinion — every internal decision cites data or is labeled a bet
2. Consent is non-negotiable — no dark patterns in data collection, ever
3. Speed beats polish — ship the smallest thing that answers a real question
4. Data is the product, not the exhaust
5. Egypt-first, not Egypt-adapted

*Source: `01_Project_Overview/PROJECT_OVERVIEW.md`*
